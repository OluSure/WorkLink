# WorkLink

WorkLink is a micro-jobs marketplace that connects people in local and low-income communities with nearby paid tasks, such as cleaning, repairs, errands, and shop assistance. Busy individuals and small businesses can quickly find trusted, affordable help, while workers can access short-term gigs through web, WhatsApp, and Email. Over time, WorkLink helps workers build a digital reputation and earning history they can use for better opportunities and financial inclusion.


![WorkLink Logo](https://cdn-icons-png.flaticon.com/128/3665/3665996.png)


## Project Overview

WorkLink addresses the growing need for flexible work arrangements by bridging the gap between talented professionals and organizations seeking remote talent. Whether you’re a freelancer, a contractor, or an employer looking to hire, WorkLink offers a streamlined process for discovering, posting, and applying to jobs.


## Features

- **Work Discovery:** Browse and filter hand-picked remote work listings.
- **Profile Management:** Create and customize workers or employer profiles.
- **Application Tracking:** Monitor your application status and get feedback.
- **Messaging:** Securely communicate with recruiters or applicants within the platform.
- **Responsive Design:** Works smoothly on desktop and mobile devices.


## Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Firebase
- **Authentication:** Firebase OAuth2 integration
- **Payment Setup:** Paystack
- **Deployment:** Vercel
